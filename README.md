# 🎯 BILE SEKO MANAGEMENT SYSTEM

**Sistem ya usimamizi wa wanachama na kufuatilia ELF 10 kila wiki**

## Features ✨

- ✅ **Admin Dashboard** - Kuona wote wote
- ✅ **Members Login** - Simu + Password + Surname
- ✅ **Weekly ELF 10 Tracking** - Kufuatilia mchango kila wiki
- ✅ **ID Card Generator** - Tengeneza ID card kutoka taarifa
- ✅ **Google Forms Integration** - Auto-upload taarifa
- ✅ **Member Dashboard** - Kila mtu anaona yao

## Tech Stack 🛠️

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Backend**: Node.js + Express
- **Database**: JSON (Local) / Firebase (Optional)
- **Hosting**: Vercel (Free)

## Setup 🚀

```bash
npm install
npm start
```

Visit: `http://localhost:3000`
